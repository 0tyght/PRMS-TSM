# LINE และการกำหนดเส้นทางรถเก็บขยะ

## ช่องทาง LINE

ระบบใช้ LINE Official Account สองบัญชีแยกกัน แต่เชื่อม API และฐานข้อมูล Smart Tha Pho ชุดเดียวกัน

| ผู้ใช้ | Webhook | เมนู |
|---|---|---|
| ประชาชน | `/api/line/webhook` | ลงทะเบียนผู้ใช้บริการ ตรวจวันเก็บขยะ ติดตามรถ ตรวจค่าบริการ และแจ้งเหตุ |
| คนขับรถ | `/api/line/driver-webhook` | เชื่อมบัญชี ดูงานวันนี้ เริ่มงาน ส่งตำแหน่ง แจ้งเหตุ และจบงาน |

ต้องสร้าง Messaging API Channel ของคนขับแยกจากบัญชีประชาชน แล้วกำหนด `LINE_DRIVER_CHANNEL_SECRET`, `LINE_DRIVER_CHANNEL_ACCESS_TOKEN` และ `LINE_DRIVER_CHANNEL_ID` ใน `.env`

## การผูกบ้านกับเส้นทาง

1. ประชาชนลงทะเบียนผ่าน LINE และส่งตำแหน่งบ้าน
2. ระบบบันทึกบ้านเป็น `UNASSIGNED` โดยยังไม่เดาเส้นทางให้อัตโนมัติ
3. หน้า **ผู้ใช้บริการ** คำนวณระยะจากบ้านถึงแนวเส้นทางที่เปิดใช้งาน และเรียงสามเส้นทางที่ใกล้ที่สุด
4. เจ้าหน้าที่ตรวจผลบนแผนที่และกด **ยืนยันเส้นทางนี้**
5. ระบบบันทึกสถานะ `CONFIRMED` พร้อมระยะทาง ผู้ยืนยัน และเวลา จากนั้นสร้างหรือปรับจุดเก็บของบ้านบนเส้นทางให้อัตโนมัติ

แนวทางนี้ลดงานเลือกจากรายการยาว แต่ยังป้องกันการกำหนดผิดจาก GPS คลาดเคลื่อน ถนนซอยแคบ หรือจุดกลับรถที่รถเก็บขยะเข้าไม่ได้

## ข้อมูลเส้นทางนำร่อง

ไฟล์ `database/demo/waste_tha_pho_routes.sql` มีข้อมูลเส้นทางนำร่องจากชื่อสถานที่ในประกาศการเก็บและขนขยะของเทศบาล ประกอบแนวถนนจาก OpenStreetMap/OSRM ข้อมูลเหล่านี้ต้องให้เจ้าหน้าที่ตรวจลำดับ จุดกลับรถ และถนนที่รถเข้าถึงได้ก่อนใช้จัดแผนจริง
