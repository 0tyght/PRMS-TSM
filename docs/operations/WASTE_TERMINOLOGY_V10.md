# มาตรฐานคำศัพท์ระบบบริหารจัดการการเก็บขยะ — V10

เอกสารนี้กำหนดคำศัพท์ที่ Source Code, Web, LINE, API message, Test และเอกสารประกอบระบบต้องใช้ให้สอดคล้องกับเอกสารการออกแบบ V10

- ระบบบริหารจัดการการเก็บขยะของเทศบาลเมืองท่าโพธิ์

- พนักงานประจำรถขยะ
- เจ้าพนักงานจัดเก็บรายได้ชำนาญงาน
- ประชาชน

## แผนภายในและข้อมูลสำหรับประชาชน

แผนปฏิบัติงานเก็บขยะเป็นข้อมูลภายในสำหรับกำหนดวันที่ เวลา/รอบ เส้นทางเก็บขยะ รถเก็บขยะ และพนักงานประจำรถขยะที่ได้รับมอบหมาย

เมื่อแผนปฏิบัติงานเก็บขยะพร้อมเผยแพร่ ระบบจึงสร้างข้อมูลสำหรับประชาชนในรูปแบบตารางกำหนดการเก็บขยะประจำพื้นที่และส่งผ่าน LINE ตาม FR17

ดังนั้นสองคำนี้เป็นคนละบริบทและห้ามใช้แทนกัน

## สถานที่รับบริการและจุดเก็บขยะ

สถานที่รับบริการคือบ้าน อาคาร หรือสถานที่ที่ผู้ใช้บริการลงทะเบียนให้เทศบาลเข้าจัดเก็บขยะ

จุดเก็บขยะคือตำแหน่งที่เทศบาลกำหนดให้รถเข้าจัดเก็บขยะและใช้จัดลำดับในเส้นทางเก็บขยะ

## สถานะที่แสดงต่อผู้ใช้

สถานะแผนหลักใช้:
- ยังไม่เริ่มปฏิบัติงาน
- กำลังปฏิบัติงาน
- ปฏิบัติงานเสร็จสิ้น

สถานะเหตุที่มีใน Implementation ปัจจุบันแสดงเป็น:
- รอรับทราบ
- รับทราบแล้ว
- ปิดเหตุแล้ว

สถานะการใช้งานของข้อมูลใช้คำว่า ใช้งาน หรือ ยกเลิกการใช้งาน ตามบริบท

## Technical identifiers

ชื่อภายในเช่น driver, driverId, waste_drivers และ API path /drivers ยังคงไว้เพื่อรักษาความเข้ากันได้ของ API และฐานข้อมูล

Technical identifier ไม่ใช่ข้อความที่แสดงต่อผู้ใช้ และข้อความภาษาไทยที่แสดงต่อผู้ใช้ต้องใช้คำมาตรฐาน V10 เท่านั้น
