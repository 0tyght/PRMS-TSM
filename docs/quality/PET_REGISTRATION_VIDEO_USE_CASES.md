# คู่มือถ่ายวิดีโอ Use Case ระบบบริหารจัดการทะเบียนสัตว์เลี้ยง

อ้างอิงเอกสารออกแบบฉบับปัจจุบันของเทศบาลท่าโพธ์ ระบบมีผู้ใช้งาน 2 กลุ่ม คือ เจ้าหน้าที่เทศบาลและเจ้าของสัตว์เลี้ยง โดยเจ้าของสัตว์เลี้ยงดำเนินการผ่าน LINE Official Account ทุกขั้นตอน

## เตรียมระบบก่อนถ่าย

1. เปิด XAMPP ให้ MySQL ทำงาน
2. รัน `start-smart-tha-pho.ps1` จากโฟลเดอร์หลัก
3. เปิด `https://0tyght.github.io/PRMS-TSM/` แล้วเลือกระบบทะเบียนสัตว์เลี้ยง
4. ตรวจว่าแดชบอร์ดแสดงแผนที่ ตัวชี้วัด และข้อมูลล่าสุดจาก LINE
5. หากต้องการเติมข้อมูลสาธิตใหม่ ให้รัน `npm run seed:pet-demo`

ข้อมูลที่ขึ้นต้นด้วย `[ข้อมูลสาธิต]`, `TP-DEMO-REG-` และ `TP-DEMO-DATA-` ไม่มี LINE User ID จริง จึงใช้สาธิตฝั่งเจ้าหน้าที่ได้โดยไม่ส่งข้อความหาประชาชน

## ข้อมูลสาธิตสำคัญ

- `เจ้าตาล` — ทะเบียนปกติ มีวัคซีนปัจจุบันและทำหมันแล้ว
- `มะลิ` — วัคซีนใกล้ครบกำหนด
- `โกโก้` — สูญหาย
- `ถุงเงิน` — ย้ายออกจากพื้นที่
- `โชคดี` — เสียชีวิต
- `ส้มจี๊ด` — ยังไม่มีประวัติวัคซีน
- `ข้าวปั้น` — มีประวัติวัคซีนที่ไม่ระบุกำหนดครั้งถัดไป
- `ดำ` — วัคซีนเกินกำหนดและทำหมันแล้ว
- `ไข่มุก`, `โมจิ`, `เจ้ามี`, `แสนดี` — ตัวอย่างข้อมูลขึ้นทะเบียนในสถานะรอตรวจ รอแก้ไข กำลังตรวจ และไม่ผ่านการตรวจสอบ

## ข้อควรระวังระหว่างถ่าย

- ใช้บัญชี LINE ทดสอบที่ได้รับอนุญาตเท่านั้น
- ไม่แสดง Channel Access Token, Channel Secret, JWT หรือข้อมูลในไฟล์ `.env`
- ก่อนกดรับรองหรือส่งกลับแก้ไข ให้ชี้ให้เห็นเลขอ้างอิงและสถานะปัจจุบัน
- หลังจบแต่ละงานจาก LINE ให้แสดงว่า Rich Menu และเมนูลัดกลับมาใช้งานได้ทันที
- การเชื่อม LINE ต้องทำโดยเจ้าของสัตว์เลี้ยง เจ้าหน้าที่ไม่กรอก LINE User ID แทน
