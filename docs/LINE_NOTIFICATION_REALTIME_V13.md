# PRMS-TSM LINE Notification Realtime V13

## หลักการ

- ไม่รอรวม 15–30 นาที
- สถานะที่ประชาชนต้องดำเนินการ (`NEED_MORE_INFO`) และผลสุดท้าย (`APPROVED`, `REJECTED`) ส่งทันทีหลังบันทึกฐานข้อมูล
- `UNDER_REVIEW` ยังเปลี่ยนสถานะและแสดงบนเว็บทันที แต่ไม่ Push ซ้ำไปหาเจ้าของ เพราะยังไม่มีสิ่งที่เจ้าของต้องดำเนินการ
- แจ้งเตือนวัคซีนรวมสัตว์ของผู้รับและครัวเรือนเดียวกันในรอบตรวจเดียว แล้ว Queue ส่งทันที
- ใช้ marker ต่อสัตว์เพื่อป้องกันการแจ้งซ้ำ แม้ข้อความจริงถูกส่งเป็นข้อความรวม
- ใช้ MySQL advisory lock ป้องกัน API หลาย instance สร้างชุดเตือนซ้ำพร้อมกัน

## ผลลัพธ์ที่คาดหวัง

บ้านหนึ่งมีสัตว์ 4 ตัวที่ถึงกำหนดวัคซีนพร้อมกัน จะได้รับ 1 ข้อความที่มีรายชื่อครบ แทน 4 ข้อความ โดยไม่มีเวลารอเพิ่มจากระบบรวมข้อความ
