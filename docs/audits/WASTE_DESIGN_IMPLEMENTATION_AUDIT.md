# ตรวจสอบระบบบริหารจัดการการเก็บขยะตามเอกสารออกแบบ

เอกสารอ้างอิง: `การออกแบบ_V3_ระบบบริหารจัดการการเก็บขยะของ (4).docx`

วันที่ตรวจสอบ: 10 สิงหาคม 2569

## สรุป

- ฝั่งเจ้าหน้าที่รองรับข้อมูลพื้นฐาน แผนปฏิบัติงานเก็บขยะ แผนที่ การติดตาม ผู้ใช้บริการ ค่าบริการ เหตุ และรายงานแล้ว
- ฝั่ง LINE รองรับการลงทะเบียนผู้ใช้บริการเก็บขยะ ตรวจตารางเก็บขยะ ตรวจตำแหน่งรถ ตรวจค่าบริการ เชื่อมบัญชีพนักงานประจำรถขยะ ดูงาน เริ่ม/จบงาน ส่งตำแหน่ง ยืนยันจุดเก็บ และแจ้งเหตุแล้ว
- การส่งข้อความค่าบริการหรือข้อความเตือนออก LINE แบบอัตโนมัติถูกแยกเป็นคิว เพื่อให้ตรวจข้อความและนโยบายข้อมูลส่วนบุคคลก่อนเปิดตัวส่งจริง
- การลบข้อมูลหลักใช้การยกเลิกการใช้งานแทนการลบถาวรเมื่อข้อมูลถูกอ้างอิงในประวัติ เพื่อรักษาความถูกต้องของรายงานและหลักฐานการปฏิบัติงาน

## หลัก UX/UI ที่ใช้

- หน้า Dashboard แสดงเฉพาะข้อมูลที่ช่วยตัดสินใจ: งานวันนี้ ความพร้อมของรถ เหตุค้างดำเนินการ ความพร้อมของข้อมูลเส้นทาง และแผนที่
- สถานที่รับบริการเลือกจากแผนที่ ไม่บังคับให้เจ้าหน้าที่กรอกละติจูด/ลองจิจูดเอง
- เส้นทางเดินรถกำหนดจากจุดควบคุมบนแผนที่ แล้วคำนวณตามแนวถนนจริง
- สถานะและการดำเนินการใช้คำเดียวกันทั้งเว็บไซต์และ LINE
- ตารางรองรับการเลื่อนแนวนอนเมื่อพื้นที่แคบ และฟอร์มปรับจากสองคอลัมน์เป็นหนึ่งคอลัมน์บนจอขนาดเล็ก
- งานที่มีผลต่อประวัติใช้ “ยกเลิก” หรือ “ยกเลิกการใช้งาน” แทนการลบถาวร
