# Smart Tha Pho — โครงสร้างแพลตฟอร์ม

Smart Tha Pho คือแพลตฟอร์มระบบงานของเจ้าหน้าที่เทศบาลท่าโพธ์ ใช้เว็บเจ้าหน้าที่และการเข้าสู่ระบบกลางร่วมกันหนึ่งชุด แล้วแยกโมดูล ข้อมูล และสิทธิ์ของแต่ละระบบออกจากกัน

```text
apps/
  portal/                       Login gateway, session และการเลือกเว็บระบบ
  prms-tsm/                     ระบบทะเบียนและบริหารจัดการสัตว์เลี้ยง (PRMS-TSM)
  waste-management/             ระบบบริหารจัดการรถเก็บขยะ
  disaster-management/          ระบบบริหารจัดการบรรเทาสาธารณภัย
  waterworks-management/        ระบบบริหารจัดการการประปา
  api/                          API กลางและบริการระบบทะเบียนสัตว์เลี้ยงที่ใช้งานอยู่
packages/
  shared/                       ชื่อแพลตฟอร์ม รายการระบบ และค่าที่ใช้ร่วมกัน
```

## การเข้าสู่ระบบ

1. เจ้าหน้าที่เลือกเว็บระบบจากหน้าเข้าสู่ระบบ Smart Tha Pho
2. ยืนยันตัวตนด้วยบัญชีเจ้าหน้าที่เพียงครั้งเดียว
3. ระบบบันทึกเฉพาะเว็บระบบที่เลือกใน session และเปิดพื้นที่ทำงานของระบบนั้น
4. เจ้าหน้าที่เปลี่ยนระบบได้จากปุ่ม `เปลี่ยนระบบ` โดยไม่ต้องกรอกรหัสผ่านซ้ำ

## ขอบเขตของแต่ละระบบ

| ระบบ | พื้นที่งาน |
| --- | --- |
| ระบบทะเบียนและบริหารจัดการสัตว์เลี้ยง | การขึ้นทะเบียนสัตว์เลี้ยง ทะเบียนเจ้าของ บริการสาธารณสุข และภาพรวมพื้นที่ |
| ระบบบริหารจัดการรถเก็บขยะ | แผนการเก็บขยะ รถและพนักงาน เส้นทางปฏิบัติงาน และแจ้งเตือนผ่าน LINE |
| ระบบบริหารจัดการบรรเทาสาธารณภัย | รับแจ้งเหตุ สถานการณ์ กำลังและทรัพยากร และแจ้งเตือนประชาชน |
| ระบบบริหารจัดการการประปา | ผู้ใช้น้ำ มิเตอร์และการใช้น้ำ ค่าบริการ และแจ้งเหตุประปา |

โมดูลทะเบียนสัตว์เลี้ยงเชื่อม API และฐานข้อมูลเดิมแล้ว ส่วนอีกสามระบบมีพื้นที่เว็บและขอบเขตโมดูลแยกไว้เรียบร้อย แต่ยังต้องเพิ่ม schema, API และหน้าการทำงานตามเอกสารออกแบบของแต่ละระบบก่อนจะแสดงข้อมูลจริงได้
